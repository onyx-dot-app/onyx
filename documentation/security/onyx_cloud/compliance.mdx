Onyx is SOC 2 Type II and GDPR compliant. This applies to both the multi-tenant and the single-tenant Onyx Cloud.

Email [hello@onyx.app](mailto:hello@onyx.app) to request the reports.

Penetration tests run every year. Onyx shares the results after you sign an NDA.
