From nothing to a working wiki your coding agent can read and write. Budget about fifteen minutes,
most of it waiting on the first build.

<Steps>
  <Step title="Run the stack">
    ```bash
    curl -fsSL https://raw.githubusercontent.com/onyx-dot-app/agent-wiki/main/install.sh | bash
    ```

    When it finishes, open `http://localhost:8090`. See [Docker Compose](/agent-wiki/deployment/docker_compose)
    for requirements, the manual path, and troubleshooting.
  </Step>

  <Step title="Claim the admin account">
    Sign up at that URL. **The first account created becomes the admin**,
    so do this before anyone else reaches the instance.
  </Step>

  <Step title="Configure a language model">
    Go to **Admin → Language Models** and add a provider.

    Nothing intelligent happens until this is set: agents, triggers, and Auto Organize all sit idle without a model.
  </Step>

  <Step title="Write a page">
    Open **Wiki** in the sidebar and create one. Pages are markdown in a folder hierarchy,
    and every save is a git commit — so nothing you do here is unrecoverable.

    Give it real content rather than a placeholder. The next step is more interesting with something to read.
  </Step>

  <Step title="Connect your agent">
    Open **Agents & Actions**, generate an API key, and point your coding agent at the wiki:

    ```bash
    claude mcp add --transport http agent-wiki \
      http://localhost:8090/api/mcp \
      --header "Authorization: Bearer mcp_REPLACE_ME"
    ```

    Full setup for Claude Code, Cursor, Codex,
    and Onyx Craft — plus the argument-order gotcha that trips up the command above — is in [Connect an
    Agent](/agent-wiki/automate/mcp).
  </Step>

  <Step title="Try it from the agent">
    Ask your agent to search the wiki, read the page you wrote, and add something to it.
    The edit shows up as a commit attributed to you, visible in the page's history.

    This is the loop the product is built around: agents load context from the wiki before working,
    and write back what they learn.
  </Step>
</Steps>
