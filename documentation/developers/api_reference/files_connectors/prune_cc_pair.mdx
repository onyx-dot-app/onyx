---
title: "Prune Cc Pair"
openapi: "POST /manage/admin/cc-pair/{cc_pair_id}/prune"
---

<Info>
  **Required permission:** Manage Connectors & Document Sets (`manage:connectors`), or Admin (`admin`).
  A **Group Manager** can also call this, limited to connector-credential pairs in the groups they manage.
</Info>

The request stays queued if pruning cannot start at once, for example during a permission sync.
Onyx retries a lost or failed task, with up to three attempts per request. After three failed attempts,
check the connector run history and submit a new request to try again.
