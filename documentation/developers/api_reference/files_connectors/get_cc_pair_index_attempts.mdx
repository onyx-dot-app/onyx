---
title: "Get CC Pair Index Attempts"
openapi: "GET /manage/admin/cc-pair/{cc_pair_id}/index-attempts"
---

<Info>
  **Required permission:** `read:connectors`, which **Manage Connectors & Document Sets** or **Manage Groups** includes.
  Admin (`admin`) also has it. A **Group Manager** can also call this,
  limited to connector-credential pairs in the groups they manage.
</Info>
