<Info>
  **Required permission:** Manage Plugins (`manage:plugins`).
  A **Group Manager** can also call this for the groups they manage,
  but only for a private Skill that they can edit and that is shared only within their groups.
</Info>

Sets the installation policy of a Skill for the members of the group.
The group policy replaces the organization setting for those members, also when it is stricter.
A `null` `installation_policy` removes the group policy, so the group uses the organization setting again.

- For a published Skill, the group gets the policy without a share.
- For a private Skill that the group does not have yet, Onyx shares the Skill with the group with **Can use**
  and the policy.
- A group with **Can edit** cannot get **Not available**.

The response lists the plugins of the group,
as in [List User Group Plugins](/developers/api_reference/user_groups/list_user_group_plugins).
