---
title: "Stop Chat Session"
openapi: "POST /chat/stop-chat-session/{chat_session_id}"
---

<Info>
  **Required permission:** Chat &mdash; Write (`write:chat`), which `basic` includes, so any signed-in user has it.
  A limited [Personal Access Token](/developers/overview#personal-access-tokens) needs the Chat &mdash; Write scope.
  A service account in no group also holds it.
</Info>
