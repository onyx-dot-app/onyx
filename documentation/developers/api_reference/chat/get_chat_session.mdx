---
title: "Get Chat Session"
openapi: "GET /chat/get-chat-session/{session_id}"
---

<Info>
  **Required permission:** Chat &mdash; Read (`read:chat`), which `basic` includes, so any signed-in user has it.
  A limited [Personal Access Token](/developers/overview#personal-access-tokens) needs the Chat &mdash; Read scope.
  Anonymous users can call this when anonymous access is enabled.
</Info>
