<Step title="Choose Visible Models">
    In the **Models** section, select the models that users can pick in chat. If a model is missing,
    open **More Models** or type its name and click **Add Model**.

    Limiting visible models helps when a provider publishes many models and versions of the same model.
</Step>

<Step title="Set Models Access">
    Under **Models Access**, choose **All Users & Agents** or **Named Groups & Agents**.

    With **Named Groups & Agents**, only Admins and the User Groups and Agents you name can use the models.
    Named groups need a Business plan or higher.
</Step>
