## How it works

The BookStack connector indexes every shelf, book, chapter, and page that the connected user can see.
Each becomes one document. A page document holds the page text.

After the first full sync, Onyx pulls new and changed content every 30 minutes by default.
You can change this under **Schedule**.

**Sync with BookStack** is not offered.
The access type can only be **Everyone in Your Organization** or **Specific Groups**.

## Setting up

### Authorization

You need API credentials for a user in your BookStack instance:

<Steps>
  <Step title="Create or select the connection user">
    Find or create the user Onyx connects as.
    - Onyx indexes only the content this user can see.
    - The user needs a role with the **Access system API** permission.
  </Step>

  <Step title="Open API Tokens">
    Edit that user with an admin account and find the **API Tokens** section at the bottom of the page.

    <img className="rounded-image" src="/assets/admins/connectors/bookstack/BookstackApiTokenList.webp" alt="BookStack API Tokens List View"/>
  </Step>

  <Step title="Create and copy the token">
    Click **Create Token**, enter a name and an optional expiry date, then save.
    Copy the **Token ID** and **Token Secret**.

    <img className="rounded-image" src="/assets/admins/connectors/bookstack/BookstackApiToken.webp" alt="BookStack API Token View"/>
  </Step>
</Steps>

### Indexing

<Steps>
  <Step title="Connect a BookStack account">
    In Onyx, go to **Admin Panel → Connectors** and select **BookStack**. Under **Authentication Account**,
    select **New Bookstack Account** and enter:

    - **Bookstack Base URL**: Your BookStack site, such as `https://bookstack.example.com`.
    - **Bookstack API Token ID**: The Token ID you copied.
    - **Bookstack API Token Secret**: The Token Secret you copied.

    <img className="rounded-image" src="/assets/admins/connectors/bookstack/BookstackAuth.webp" alt="BookStack account form in Onyx"/>
  </Step>

  <Step title="Enter the site URL">
    In **BookStack Base URL**, enter the same site URL. BookStack's REST API must be reachable at this address.
  </Step>

  <Step title="Choose who can see the content">
    Under **Document Access**, select **Everyone in Your Organization** or **Specific Groups**.
    **Specific Groups** is available on Onyx Cloud and Enterprise Edition.
  </Step>

  <Step title="Create the connector">
    Select **Create Connector**. Onyx checks the URL and tokens before it saves the connector.
    Open **Admin Panel → Indexing Status**, select the connector, and confirm its first indexing attempt completes.

    <img className="rounded-image" src="/assets/admins/connectors/bookstack/BookstackIndex.webp" alt="BookStack connector form in Onyx"/>
  </Step>
</Steps>
