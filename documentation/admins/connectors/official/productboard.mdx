## How it works

The Productboard connector indexes the **Features**, **Components**, **Products**,
and **Objectives** in your Productboard workspace. Each one becomes a searchable document in Onyx.

Onyx does not index **Notes**, **Releases**, or the comments on a feature.
The Productboard public API does not expose them in a form Onyx can index.

Onyx pulls new and changed items on the connector's **Refresh Every** schedule. The default is **30 minutes**.

## Setting up

### Authorization

<Steps>
  <Step title="Get an access token">
    Follow the Productboard [public API access token
    guide](https://developer.productboard.com/#section/Authentication/Public-API-Access-Token)
    to create an access token. Onyx reads data as the user who created the token.
  </Step>
</Steps>

### Indexing

<Steps>
  <Step title="Create an authentication account">
    In Onyx, go to **Admin Panel → Connectors** and select **Productboard**. Under **Authentication Account**,
    select **Create New**. Enter a **Display Name**, paste the token into **API Token**, and select **Create**.
  </Step>

  <Step title="Configure the connector">
    Under **Connector Settings**, give the connector a **Display Name**. The connector has no other settings.

    Under **Document Access**, choose who can see the indexed items.
    **Everyone in Your Organization** shows them to all Onyx users.
    **Specific Groups** limits them to the Onyx user groups you pick. **Specific Groups** is a paid feature:
    the Business and Enterprise tiers on Onyx Cloud, and the Enterprise Edition when self-hosted.
    The Productboard connector does not sync Productboard permissions.
  </Step>

  <Step title="Start indexing">
    Select **Create Connector** to save the connector and start indexing.
    Open **Admin Panel → Indexing Status** and select the connector to follow the first indexing run.
  </Step>
</Steps>
