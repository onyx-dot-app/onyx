This guide sets up the Google Drive connector with an OAuth app in Google Cloud. It works with any Google account,
with or without a paid Google Workspace.

If your organization has a Google Workspace and you prefer a service account,
follow the [Service Account guide](./service_account).

### Authorization

<Steps>
  <Step title="Create a Google Cloud project">
    Go to [https://console.cloud.google.com/projectcreate](https://console.cloud.google.com/projectcreate)
    and create a project.
  </Step>

  <Step title="Enable the Google Drive API">
    - In the left panel, open **APIs & services** and go to **Enabled APIs and services**.
    - Click **+ ENABLE APIS AND SERVICES**.
    - Search for **Google Drive API** and click **ENABLE**.
  </Step>

  <Step title="Enable the Admin SDK API">
    - Click **+ ENABLE APIS AND SERVICES** again.
    - Search for **Admin SDK API** and click **ENABLE**.
  </Step>

  <Step title="Enable the Google Sheets API">
    - Click **+ ENABLE APIS AND SERVICES** again.
    - Search for **Google Sheets API** and click **ENABLE**.
  </Step>

  <Step title="Enable the Google Docs API">
    - Click **+ ENABLE APIS AND SERVICES** again.
    - Search for **Google Docs API** and click **ENABLE**.

    <img className="rounded-image" src="/assets/admins/connectors/google_drive/GoogleDriveEnableAPI.webp" alt="Google Cloud Console enabling the Google Docs API for the project"/>
  </Step>

  <Step title="Set up the OAuth consent screen">
    - Under **APIs & services**, select **OAuth consent screen**.
    - If you do not have a Google organization, select **External** as the **User Type**.
    - Name the app and enter the required contact emails.
  </Step>

  <Step title="Add the scopes">
    - Add the scope `.../auth/drive.readonly` for the **Google Drive API**.
    - Add the scope `.../auth/drive.metadata.readonly` for the **Google Drive API**.
    - Add the scope `.../auth/admin.directory.user.readonly` for the **Admin SDK API**.
    - Add the scope `.../auth/admin.directory.group.readonly` for the **Admin SDK API**.

    <img className="rounded-image" src="/assets/admins/connectors/google_drive/GoogleDriveScopes.webp" alt="OAuth consent screen scopes for Google Drive and the Admin SDK"/>
  </Step>

  <Step title="Add test users">
    This step applies only to apps without a Google organization.
    - Add at least one test user email. Only these accounts can run the OAuth flow.
  </Step>

  <Step title="Create the OAuth client">
    Go to the **Credentials** tab and select **+ CREATE CREDENTIALS > OAuth client ID**.

    <img className="rounded-image" src="/assets/admins/connectors/google_drive/GoogleDriveCredential.webp" alt="Creating an OAuth client ID in Google Cloud Console"/>

    - Choose **Web application** and name it, for example `OnyxConnector`.
    - Add an **Authorized JavaScript origin**:
    - `http://localhost:3000` for a local deployment
    - `https://<YOUR_ONYX_URL>` for a self-hosted deployment
    - `https://cloud.onyx.app` for Onyx Cloud
    - Add an **Authorized redirect URI**:
    - `http://localhost:3000/admin/connectors/google-drive/auth/callback` for a local deployment
    - `https://<YOUR_ONYX_URL>/admin/connectors/google-drive/auth/callback` for a self-hosted deployment
    - `https://cloud.onyx.app/admin/connectors/google-drive/auth/callback` for Onyx Cloud

    <img className="rounded-image" src="/assets/admins/connectors/google_drive/DriveCredentials.webp" alt="Authorized origins and redirect URIs for the Google Drive OAuth client"/>

    Click **CREATE**. Next to **Client secret**, download the client as JSON.

    <img className="rounded-image" src="/assets/admins/connectors/google_drive/DriveDownloadCredentials.webp" alt="Download the OAuth client JSON from Google Cloud Console"/>
  </Step>
</Steps>

### Indexing

<Steps>
  <Step title="Create the account">
    In the Onyx admin panel, go to **Connectors** and select **Google Drive**. Under **Authentication Account**,
    click **Create New** and select **OAuth**. Upload or paste the OAuth app JSON you downloaded above.
    Click **Authenticate with Google Drive** and sign in with the Google account whose Drive you want to index.

    <img className="rounded-image" src="/assets/admins/connectors/google_drive/OAuthCredential.webp" alt="Google Drive account form in Onyx with the Service Account and OAuth options"/>
  </Step>

  <Step title="Choose what to index">
    Under **General**, select **Include Shared Drives**, **Include My Drive**, or **Include All Files Shared with You**.
    Or open **Specific** and enter **Shared Drive URLs** and **Folder URLs**.
    See the [Google Drive overview](./overview) for the details of each option.
  </Step>

  <Step title="Choose document access">
    Under **Document Access**, select who can see the indexed files.
    **Sync with Google Drive** mirrors each user's own access in Google Drive.
    **Specific Groups** and **Sync with Google Drive** are available on the Business and Enterprise plans and on Onyx
    Cloud. Then click **Create Connector**.
  </Step>
</Steps>

<Note>
  The app JSON is stored on the account it creates, so each OAuth account carries its own app.
  To add more connectors for the same Google account,
  select the existing account under **Authentication Account** instead of creating a new one.
  An instance can hold multiple Google Drive accounts,
  including ones that use different OAuth apps or different Google Workspaces.
</Note>

<Note>
  To use **Sync with Google Drive**,
  sign in with an account that has an admin role in the Google Workspace with these privileges:
  - Admin console privileges > Services > Drive and Docs > Settings
  - Admin API privileges > Users > Read
  - Admin API privileges > Groups > Read
  - Admin API privileges > Organization Units > Read

  Set the role in the Google Admin console under **Account > Admin roles**.
</Note>

### Using one account for Gmail and Google Drive

A Google account created in Onyx is listed on both the Gmail and the Google Drive connector forms,
so one account can index both. For this reason, the Google consent screen asks for the scopes of both connectors:

| Connector    | Scopes                                                                                   |
| ------------ | ---------------------------------------------------------------------------------------- |
| Google Drive | `drive.readonly`, `drive.metadata.readonly`, `admin.directory.user.readonly`, `admin.directory.group.readonly` |
| Gmail        | `gmail.readonly`, `admin.directory.user.readonly`, `admin.directory.group.readonly`       |

- To use the account for both connectors, grant every scope on the consent screen. Add the scopes of both connectors
  to your app's OAuth consent screen, and add the redirect URI of each connector form you authenticate from.
- To use the account for Google Drive only, untick the Gmail scopes on the consent screen. The account then works only
  for Google Drive. The connector checks report the missing scopes if you select it for Gmail.

To add the other connector's scopes later, authenticate the account again and grant them.
