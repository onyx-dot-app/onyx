---
title: "Google Drive Service Account"
description: "Set up Google Drive Service Account for the connector"
---

A Google Workspace is required. For more on Service Accounts,
see the [Google Cloud documentation](https://cloud.google.com/iam/docs/service-account-overview).

To use an individual account with OAuth instead, see the guide [here](./oauth).

### Authorization

<Steps>
  <Step title="Create Google Cloud Project">
    - [https://console.cloud.google.com/projectcreate](https://console.cloud.google.com/projectcreate)
  </Step>

  <Step title="Enable required APIs">
    Under **APIs & services → Enabled APIs and services**,
    select **+ENABLE APIS AND SERVICES** and enable the **Google Drive API**, the **Admin SDK API**,
    the **Google Docs API**, and the **Google Sheets API**.
    This [link](https://console.cloud.google.com/flows/enableapi?apiid=drive.googleapis.com)
    enables the **Google Drive API** directly.

    <img className="rounded-image" src="/assets/admins/connectors/google_drive/GoogleDriveEnableAPI.webp" alt="Google Cloud Console enabling Drive, Admin SDK, Docs, and Sheets APIs"/>
  </Step>

  <Step title="Create Service Account">
    - Go to the [Service Account management page](https://console.cloud.google.com/iam-admin/serviceaccounts) in Google Cloud.
    - Click `Create Service Account` button and fill out the fields in step 1. You can ignore steps 2 and 3.
    - Go to the `Keys` section, and click `Add Key`. Download this key.

    Note for Google Organizations created after April 2024:
    - To give the service account the proper permissions you will have to navigate to this [link](https://console.cloud.google.com/iam-admin/orgpolicies/iam-disableServiceAccountKeyCreation)
    - Then select `Manage`, select `Override parent's policy` and then select `Not enforced` under `Rules`.
    - Finally, select `SET POLICY`

    <iframe
    width="840" height="473" src="https://www.youtube.com/embed/Z5R9HUCVVAE?si=GZxteF6rmIHa1BOE" title="YouTube video
    player" frameBorder="0" allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope;
    picture-in-picture; web-share; fullscreen;" allowfullscreen
    ></iframe>
  </Step>

  <Step title="Grant domain-wide delegation">
    Give this **Service Account** read-only access to Google Drive
    - Copy the `Unique ID` of the Service Account
    - Go to the [Domain-wide Delegation page](https://admin.google.com/ac/owl/domainwidedelegation) in the Google Admin Console.
    - Click `Add new`, fill in the client ID with the `Unique ID` of the Service account
    - Copy this comma separated list of scopes and paste it into field `OAuth scopes`:
    `https://www.googleapis.com/auth/drive.readonly,https://www.googleapis.com/auth/drive.metadata.readonly,https://www.googleapis.com/auth/admin.directory.group.readonly,https://www.googleapis.com/auth/admin.directory.user.readonly`

    picture-in-picture; web-share; fullscreen;" allowfullscreen

  </Step>
</Steps>

### Indexing

<Steps>
  <Step title="Create the credential">
    Go to **Admin Panel → Connectors** and select **Google Drive**.
    Select **New Google Drive Account** and choose the **Service Account** method.
    Upload or paste the JSON key you downloaded in **Service Account Key**.

    For the **Primary Admin Email**, use the email of a user that:
    - Has access to `Drive and Docs` in Google Workspace
    - Has the following admin permissions:
    - Admin console privileges -> Services -> Drive and Docs -> Settings
    - Admin API privileges -> Users -> Read
    - Admin API privileges -> Groups -> Read
    - Admin API privileges -> Organization Units -> Read

    This can be an existing admin, or a new account created for Onyx (for example `onyx-robot@your-domain.com`).
    It must *NOT* be the service account email.
    A Google Workspace admin grants these permissions under Account > Admin roles.

    <img className="rounded-image" src="/assets/admins/connectors/google_drive/ServiceAccountCredential.webp" alt="Onyx Google Drive connector with Service Account credential and Primary Admin Email"/>

    Select **Create**.
  </Step>

  <Step title="Configure the connector">
    Choose what to index and who can see it. See the [Google Drive overview](./overview#choosing-what-to-index)
    for every setting. Select **Create Connector** when the required checks pass.
  </Step>
</Steps>

<Note>
  You can create more than one Google Drive credential on a single Onyx instance, each with its own service account.
  This lets you index multiple Google Workspaces from one Onyx deployment.
</Note>

<Note>
  A Google credential is listed on both the Gmail and the Google Drive connector forms.
  To use one service account for both connectors, delegate the scopes of both:
  `https://www.googleapis.com/auth/gmail.readonly,https://www.googleapis.com/auth/drive.readonly,https://www.googleapis.com/auth/drive.metadata.readonly,https://www.googleapis.com/auth/admin.directory.group.readonly,https://www.googleapis.com/auth/admin.directory.user.readonly`.
  With only one connector's scopes delegated, the credential works for that connector only.
</Note>
