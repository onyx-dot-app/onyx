title: "Connectors"
description: "Set up and manage data source connectors"
icon: "plug"
---

Connectors bring documents from your tools into Onyx so chat, Search Mode, and Agents can use them.
Admins add and manage connectors in the Admin Panel under **Connectors** and **Indexing Status**.

See the [Connectors overview](/admins/connectors/overview) for the full guide and the list of supported sources.
