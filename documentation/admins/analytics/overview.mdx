Onyx gives admins two dashboards under the **Usage** section of the Admin Panel.

## Usage

Open **Admin Panel > Usage** to see model usage and spend for a period.

- **Usage overview**: active users, workspace spend, total tokens, and the top spender.
- **Users**: spend and tokens for each user, sorted highest first.
  Filter the list and select a user for a full breakdown by model and feature.
- **System usage**: tokens used by background features that are not tied to one user, such as contextual retrieval.

Costs come from the recorded model usage and the price list for each model.
Admins can also reset a user's usage window from this page if a [spending
limit](/admins/advanced_configs/spending_limits) blocks them.

Each user can see their own usage in **User Settings > Usage**.

## Analytics

Open **Admin Panel > Analytics** to see activity over time.

- **Usage**: queries and unique users per day.
- **Feedback**: thumbs up and thumbs down over time.
- **Slack channels**:
  total queries and auto-resolved questions from the [Slack Integration](/admins/getting_started/slack_bot_setup).
- **Agent Analytics**: messages and unique users per day for a selected Agent.

### Usage reports

On the Analytics page you can generate a usage report for a period, or for all time.
The report is a ZIP of CSV files with per-user and per-system usage.
Reports build in the background and stay available on the page for later download.

## Query History

See [Query History](/admins/analytics/query_history) to review and export individual chat sessions.
