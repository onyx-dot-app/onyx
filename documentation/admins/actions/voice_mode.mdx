Voice lets your users speak to Onyx and hear its replies. A speech-to-text (STT)
provider turns the user's speech into a chat message. A text-to-speech (TTS) provider reads the Agent's reply aloud.

Both directions are off until an admin connects a provider and sets it as the default. Until then,
the microphone button and read-aloud controls are hidden in chat.

## Set up Voice

<Steps>
  <Step title="Set up a Speech to Text provider">
    Open **Admin Panel → Voice**. In **Speech to Text**,
    click **Connect** on a model and enter the provider credentials.

    <img className="rounded-image" src="/assets/admins/actions/voice-mode/voice_mode_dashboard.webp" alt="Voice page in the Onyx Admin Panel"/>

    <img className="rounded-image" src="/assets/admins/actions/voice-mode/stt.webp" alt="Speech to Text models"/>

    <Tabs tabs={["Whisper", "Azure Speech", "ElevenAPI", "Zoom Scribe"]}>
      <Tab title="Whisper">
        Create an API key in the [OpenAI dashboard](https://platform.openai.com/api-keys),
        or reuse an OpenAI key you already use for a chat model. Enter it in the **API Key** field.
      </Tab>

      <Tab title="Azure Speech">
        Speech to text in Azure Speech Services (Microsoft Foundry Tools).

        1. In the [Azure Portal](https://portal.azure.com), create a Speech resource.
        2. Copy the key and the endpoint from **Keys and Endpoint**.
        3. In Onyx, paste the key in **API Key** and the endpoint in **Target URI**. Onyx reads the region from the
        endpoint URL.
        4. In **Spoken Languages**, enter the locales your users speak, for example `en-US, fr-FR`. With more than
        one locale, live transcription detects the spoken language.
      </Tab>

      <Tab title="ElevenAPI">
        Create an API key in the [ElevenLabs dashboard](https://elevenlabs.io/app/settings/api-keys)
        and enter it in the **API Key** field.
      </Tab>

      <Tab title="Zoom Scribe">
        Zoom Scribe real-time speech-to-text from Zoom AI Services. Zoom supports speech to text only.

        1. Create credentials in [Zoom AI Services](https://developers.zoom.us/docs/ai-services/).
        2. In Onyx, enter the **API Key** and **API Secret**.
        3. Select the **Spoken Language** that Zoom Scribe should transcribe.

        The Zoom connection is shared with **Decision Models** in the Admin Panel. Both pages use the same credentials.
        Setting up Zoom here does not select a decision model.
      </Tab>
    </Tabs>
  </Step>

  <Step title="Set up a Text to Speech provider">
    In **Text to Speech**, click **Connect** on a model and enter the provider credentials.

    <img className="rounded-image" src="/assets/admins/actions/voice-mode/tts.webp" alt="Text to Speech models"/>

    <Tabs tabs={["OpenAI TTS-1 and TTS-1 HD", "Azure Speech", "ElevenAPI"]}>
      <Tab title="OpenAI TTS-1 and TTS-1 HD">
        Create an API key in the [OpenAI dashboard](https://platform.openai.com/api-keys),
        or reuse the key from Whisper. Enter it in the **API Key** field.

        In **Default Model**, choose **TTS-1** (optimized for speed) or **TTS-1 HD** (optimized for quality).
      </Tab>

      <Tab title="Azure Speech">
        Use the same Speech resource as for speech to text.
        Paste the key in **API Key** and the endpoint in **Target URI**.
      </Tab>

      <Tab title="ElevenAPI">
        Create an API key in the [ElevenLabs dashboard](https://elevenlabs.io/app/settings/api-keys)
        and enter it in the **API Key** field.
      </Tab>
    </Tabs>

    In the **Voice** field, select a voice from the list or enter a voice ID. Onyx uses this voice for spoken responses.

    <img className="rounded-image" src="/assets/admins/actions/voice-mode/voice_selection.webp" alt="Voice selection in the provider setup dialog"/>
  </Step>

  <Step title="Set the default providers">
    Click **Set as Default** on the STT model and on the TTS model you want to use.
    You can use one provider for speech to text and a different provider for text to speech.

    <img className="rounded-image" src="/assets/admins/actions/voice-mode/set_default.webp" alt="Set as Default on a Speech to Text model"/>

    Disconnecting a provider removes its stored credentials.
  </Step>
</Steps>

## Using Voice in chat

Each user can turn on **Auto-Send on Pause** and **Auto-Playback** and set the **Playback Speed** under **Settings >
Voice**.

<Note>
  Onyx does not store audio. Recorded speech goes to the STT provider and only the transcript is kept,
  as a normal chat message. Synthesized audio streams to the browser and is not saved.
</Note>
