# Connectors

Onyx Dot App supports various connectors to integrate with different services. Here are some of the available connectors:

- [Jira Service Management](connector/jira_service_management.py)

## Adding New Connectors
To add a new connector, follow these steps:
1. Create a new Python file in the `connector` directory.
2. Implement the necessary methods to interact with the service.
3. Update the README.md file to include instructions on adding the new connector.
