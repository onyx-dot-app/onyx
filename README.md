# Onyx Dot App

Onyx Dot App is a powerful AI-powered tool for managing tasks and projects. It integrates with various services, including Jira Service Management.

## Connectors
- [Jira Service Management](connector/jira_service_management.py)

## Getting Started
1. Install the app using pip:
   ```bash
   pip install onyx-dot-app
   ```
2. Configure the connector by editing `config.yaml` and adding your Jira credentials.
3. Run the app to start managing tasks and projects.
